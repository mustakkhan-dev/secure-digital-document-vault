Core Capabilities

Designed for Zero-Trust Cloud Security

Every layer is backed by AWS managed services, eliminating single points of failure and protecting sensitive documents.

Cognito Identity Auth

Fine-grained user isolation powered by Amazon Cognito User Pools with cryptographic RS256 JWT claim verification on every API transaction.

Encrypted S3 Storage

Documents are stored in a private Amazon S3 bucket with all Block Public Access settings enforced and KMS/AES256 server-side encryption.

Revocable Share Links

Create time-bounded share tokens. Overcomes presigned URL limitations by enabling instantaneous owner-controlled link revocation.

Automated Expiry Alerts

Amazon EventBridge triggers daily scans to notify users via Amazon SNS email notifications before passports or certificates expire.

Security Audit Logging

Comprehensive event tracking recording logins, uploads, downloads, and unauthorized access attempts in Amazon DynamoDB.

DevOps Automated CI/CD

Infrastructure as Code codified in Terraform, with automated GitHub Actions testing and deployment via AWS OIDC authentication.

System Design

AWS Serverless Architecture

Decoupled, event-driven infrastructure ensuring high availability, sub-second latency, and zero server maintenance.

1

Amazon Cognito

Authenticates user identity, enforces password policies, and returns signed JWT tokens.

2

Amazon API Gateway

Validates JWT tokens via HTTP API authorizer and securely routes requests to microservices.

3

AWS Lambda

Executes stateless business logic for upload URLs, downloads, revocation, and logging.

4

Amazon S3 Private

Stores binary files with Block Public Access and AES256 server-side encryption enabled.

5

Amazon DynamoDB

Maintains document catalog, TTL share tokens, and tamper-evident audit logs.

// DIRECT-TO-S3 ZERO-TRUST UPLOAD FLOW
1. Client Browser → API Gateway (POST /documents/upload-url + Bearer JWT)
2. API Gateway Authorizer verifies Cognito RS256 signature → forwards to Lambda
3. Lambda validates filetype whitelist, verifies size ≤ 10MB → generates Presigned S3 PUT URL (600s)
4. Lambda inserts metadata into DynamoDB `Vault_Documents` table
5. Client Browser transfers binary directly to S3 via HTTP PUT (zero RAM overhead on Lambda)
